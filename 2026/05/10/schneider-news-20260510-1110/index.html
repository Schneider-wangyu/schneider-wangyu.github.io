施耐德电气2026年新品发布：EcoStruxure边缘控制器与智能配电新品

施耐德电气在2026年汉诺威工业博览会上发布了一系列重磅新品，涵盖边缘控制、智能配电和工业软件三大领域。这些新品进一步强化了EcoStruxure平台的能力，为工业客户的数字化转型提供了更强大的技术工具。本文详细介绍核心新品的技术特点与应用场景。

一、EcoStruxure Edge Controller——新一代边缘控制器

1.1 产品定位与架构

EcoStruxure Edge Controller是施耐德电气推出的融合型边缘控制平台，将PLC的实时控制能力与边缘计算的数据处理能力集于一身。硬件采用多核ARM Cortex-A72处理器，运行Linux实时内核，同时支持IEC 61131-3编程和Python/C++边缘应用开发。

该产品填补了传统PLC与工业PC之间的空白：既具备PLC的确定性和可靠性（最短任务周期1ms），又拥有边缘侧的数据分析和协议转换能力。

1.2 核心技术亮点

  • 双域运行：实时控制域（RTOS）和边缘计算域（Linux）并行运行，通过共享内存实现微秒级数据交换
  • 协议原生支持：内置Modbus TCP、OPC UA、EtherNet/IP、MQTT协议栈，无需额外通信模块
  • 容器化部署：边缘计算域支持Docker容器，可部署第三方AI推理引擎和数据分析应用
  • 安全启动：基于硬件信任根的安全启动链，防止固件篡改

1.3 典型应用场景

  • 产线设备的数据采集与边缘预处理
  • 预测性维护的边缘AI推理
  • 多协议设备的网关转换
  • 分布式能源的本地控制与调度

二、Premset Air——新一代智能中压开关柜

2.1 产品特点

Premset Air是施耐德电气在SF6-free（无六氟化硫）技术路线上的最新成果，采用干燥空气作为绝缘介质，全球变暖潜能值（GWP）为1，相比传统SF6绝缘方案降低了99.99%的温室气体排放。

技术规格方面，Premset Air支持12kV/24kV额定电压，额定电流至1250A，短路开断能力25kA，性能指标全面对标SF6绝缘产品。

2.2 智能化升级

Premset Air集成了施耐德电气最新的EcoStruxure传感器模块：

  • 局部放电在线监测：UHF传感器实时检测绝缘状态
  • 触头温度监测：无线测温传感器，精度±1°C
  • 机构特性监测：记录分合闸时间-行程曲线，预判机构故障

所有传感器数据通过内置OPC UA服务器对外发布，支持与EcoStruxure Asset Advisor无缝对接，实现开关柜的全生命周期健康管理。

三、EcoStruxure Machine Expert 3.0

3.1 软件平台升级

EcoStruxure Machine Expert 3.0是施耐德电气机器控制软件的重大版本更新，核心升级包括：

  • OPC UA信息模型自动生成：PLC变量可直接发布为OPC UA节点，支持自定义类型定义，免去手动配置地址映射的工作
  • 边缘应用集成开发：在同一工程中开发PLC逻辑和Python边缘脚本，支持联合调试
  • 数字孪生仿真：集成3D物理引擎，可在虚拟环境中验证控制逻辑，减少现场调试时间
  • AI辅助编程：基于自然语言描述自动生成IEC 61131-3结构化文本代码，开发效率提升40%

3.2 开放生态

Machine Expert 3.0开放了插件SDK，第三方开发者可以开发自定义功能块、通信驱动和可视化组件。施耐德电气同步推出在线插件市场，首批上架50余个社区贡献的扩展包。

四、Impact软件平台更新

施耐德电气的电力系统分析软件Impact也迎来了重要更新。新版支持从EcoStruxure直接导入配电网拓扑和设备参数，实现”设计-运行”数据贯通。新增的碳排放追踪模块可计算配电网各节点的碳流分布，为企业碳管理提供数据支撑。

五、总结

这批新品集中体现了施耐德电气的技术战略方向：无SF6化、边缘智能化和软件平台化。EcoStruxure Edge Controller代表了控制设备的演进方向——从单一功能控制器到融合型边缘智能平台。Premset Air则标志着中压配电设备正式进入零碳排放时代。这些产品的推出，将进一步巩固施耐德电气在能源管理和工业自动化领域的领先地位。
