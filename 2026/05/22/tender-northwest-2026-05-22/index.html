西北地区自动化控制系统招标信息周报（2026年5月第4周）

西北地区自动化控制系统招标信息周报（2026年5月第4周）

本期汇总2026年5月16日-22日西北五省（陕西、甘肃、青海、宁夏、新疆）及山西地区自动化控制相关招标、中标及市场动态信息。

一、重点招标项目

1. 国网宁夏电力2026年配网物资第一次枢架协议公开招标（线缆类）

  • 招标人：国网宁夏电力有限公司
  • 代理机构：宁夏天鹰电力物资有限公司
  • 招标内容：配网物资协议库存采购（线缆类）
  • 文件获取：2026年5月19日-5月27日
  • 资金来源：企业自有资金100%
  • 关注点：配电侧物资大规模采购，配电柜、环网柜等成套设备供应商可重点关注

2. 国家电网2026年度西北、西藏区域第一次联合采购（SL2653）中标公示

  • 采购编号：SL2653
  • 中标公示日：2026年5月18日
  • 采购内容：10kV变压器、10kV柱上变压器台成套设备协议库存
  • 总规模：16.8亿元，11类109包，47家中标
  • 中标亮点：宁波奥克斯智能科技以7938万元居首，21家企业超4000万元
  • 品类分布：
    • 10kV变压器：6类13包16434万元（占9.8%）
    • 柱上变压器台成套设备：5类96包151566万元（占90.2%），其中叠铁芯台成套设备40包55242万元、非晶合金台成套设备25包51601万元
  • 关注点：西北西藏区域联合采购规模庞大，柱上变压器台成套设备占比超九成，配电自动化设备供应商应积极跟进后续批次

3. 国家电网2026年度西北、西藏区域联合采购（SL2654）

  • 采购编号：SL2654
  • 采购内容：一二次融合成套环网箱、一二次融合成套柱上断路器、电能计量箱协议库存
  • 发布日期：2026年4月24日
  • 关注点：一二次融合设备是配网自动化核心产品，PLC/SCADA系统集成商可关注配套机会

4. 国网青海省电力公司2026年第三次物资公开招标（282603）

  • 招标编号：282603
  • 状态：中标候选人已公示
  • 关注点：青海地区物资采购持续释放，配网自动化设备需求稳定

5. 国家电投青海海南清洁能源基地外送工程（配套）4×660MW煤电项目

  • 中标金额：30.83亿元
  • 三大主机中标：
    • 锅炉设备：上海锅炉厂有限公司，180580万元
    • 汽轮发电机组：上海电气集团股份有限公司，127720万元
  • 关注点：超大煤电项目配套自动化控制系统需求巨大，DCS、PLC控制系统供应商可跟踪后续辅机招标

6. 国网青海省电力公司2026年紧急项目物资第二次公开招标（2826JD）

  • 发布平台：国家电网新一代电子商务平台
  • 关注点：紧急项目物资采购，自动化仪表、保护装置类需求可能加速释放

二、供热自动化专区

喀什市集中供热老旧换热站升级改造项目

  • 项目内容：改造换热站191座，更换热力管道阀门12000个
  • 设备需求：
    • 149座换热站更换静音泵、变压器、其他主要设备
    • 42座换热站更换隔音泵50套（循环泵、补水泵各100台）
    • 191座换热站配套设施改造及安装
  • 关注点：大规模换热站改造项目，PLC控制柜、变频柜、配电柜需求量大

阿克苏阳光热力智慧供热节能改造工程

  • 项目内容：换热站增设节能调控系统
  • 关注点：智慧供热是西北供热升级核心方向，PLC控制系统、变频调速设备、远程监控平台供应商重点关注

新疆换热站设备维护与采购动态

  • 同方能源新疆换热站设备维护保养服务项目（克拉玛依市，含自控系统）
  • 新疆霍尔果斯永嘉产业智能制造中心换热站设备采购项目
  • 华电新疆昌吉分公司换热站高耗能淘汰目录机电设备更新
  • 第五师双河市城区换热站提升改造建设项目
  • 塔城地区裕民县地下管网老化更新改造项目二期换热站改造
  • 第八师石河子市2026年老旧供热一次网改造建设项目

三、市场动态

陕武直流2026年度检修启动

5月19日，陕北—湖北±800千伏特高压直流输电工程（陕武直流）2026年度检修正式启动。陕武直流是”西电东送””北电南供”重要能源通道，检修期间相关自动化保护设备、监控系统的检测更新需求值得关注。

山西2026首批35个风光项目竞配落地

山西省能源局发布2026年第一批竞争性配置风电、光伏发电项目评审结果，35个项目入选，合计装机规模449.5万千瓦。项目涉及国家电投、中广核、三一重工、晶科等行业龙头。风电项目占近六成，光伏约三成，朔州项目最多。

自动化机会：风光电站配套自动化控制系统（升压站监控、SVG无功补偿控制、箱变测控等）需求将随项目推进逐步释放。

甘肃成套配电设备市场持续扩容

甘肃省2025年电网建设投资突破120亿元，”十五五”开局期配电侧改造与新增需求双重驱动。重点关注：

  • 甘肃华宇电力设备有限公司：注册资本2000万元，覆盖GGD/GCS/MNS/KYN28高低压配电柜、变频柜、PLC控制柜全系列，服务网络覆盖甘青两省及西北其他三省
  • 甘肃高低压配电柜选型趋势：智能化、适配西北干燥多尘及高海拔低温环境成为采购核心考量

换热站控制系统供应商动态

陕西迈科机电科技有限公司在西北市场持续深耕，主攻PLC控制柜、变频柜、配电柜定制化集成，过去两年完成超70个成套控制柜项目。其变频柜内增加滤波组件减少电磁干扰，出厂前执行24小时连续带电测试，体现了西北市场对设备可靠性的高要求。

甘肃省红光晟达工贸有限责任公司全自动模板机采购

  • 类型：公开招标
  • 发布日期：2026年5月21日
  • 关注点：自动化设备采购需求延伸至制造业领域

四、行业趋势

“十五五”电网投资超5万亿元

中央政治局会议将”六张网”建设纳入顶层部署，”十五五”时期电网总投资预计突破5万亿元。西北地区作为新能源基地和电力外送枢纽，自动化控制系统需求将持续增长。

一二次融合设备成为配网自动化重点

国网西北区域联合采购集中在一二次融合环网箱和柱上断路器，反映配网自动化正从传统设备向智能化、融合化方向升级。SL2653项目16.8亿元的中标规模进一步验证了这一趋势。

甘肃储能装机突破900万千瓦

甘肃新型储能装机突破900万千瓦，相当于5.5个刘家峡水电站。储能配套BMS、EMS、PCS等自动化控制系统需求持续旺盛。

五、商机建议

  1. 配网自动化：国网西北区域联合采购（SL2653/2654）持续释放，一二次融合设备、配电终端、通信模块需求旺盛，16.8亿中标规模验证市场空间
  2. 供热自动化：新疆换热站改造项目密集（喀什191座、阿克苏智慧供热、石河子老旧改造），PLC控制柜、变频柜、SCADA系统集成需求稳定
  3. 新能源配套：山西449.5万千瓦风光竞配项目落地、甘肃储能装机突破900万千瓦，配套自动化监控及保护系统需求持续增长
  4. 煤电升级：青海30.83亿元煤电项目三大主机已定标，后续辅机及DCS/PLC控制系统招标可跟踪
  5. 智慧水务：西北地区水务信息化升级加速，PLC控制柜、SCADA系统集成项目值得关注
