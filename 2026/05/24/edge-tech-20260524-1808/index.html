边缘AI推理框架选型：ONNX Runtime vs TensorRT vs TFLite

边缘AI推理框架选型：ONNX Runtime vs TensorRT vs TFLite

边缘控制器部署AI模型，框架选型直接影响推理延迟和资源占用。

选型建议

  • 通用工业视觉（x86）：ONNX Runtime + OpenVINO
  • 高性能GPU推理（Jetson）：TensorRT
  • 低功耗嵌入式（ARM+NPU）：TFLite + NNAPI

延迟对比（YOLOv5s）

Jetson Xavier上：ONNX Runtime 45ms，TensorRT FP16 15ms，TensorRT INT8 8ms。

选型原则：追求通用性选ONNX Runtime，极致性能选TensorRT，嵌入式低功耗选TFLite。
