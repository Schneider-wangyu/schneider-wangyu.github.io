## 二、边缘网关部署实践

### 2.1 协议兼容配置

边缘网关需要对接多种工业协议，以下是基于Modicon M580控制器的典型配置：

```python
# OPC UA边缘通信配置示例
from opcua import Client

class EdgeGateway:
    def __init__(self, endpoint):
        self.client = Client(endpoint)
        self.client.set_security_string(
            "Basic256Sha256,SignAndEncrypt,cert.pem,key.pem"
        )
    
    def connect_plc(self):
        """连接Modicon M580 PLC"""
        self.client.connect()
        root = self.client.get_root_node()
        # 订阅开关柜状态节点
        objects = root.get_child(["0:Objects"])
        switchgear = objects.get_child(["2:SwitchGear", "2:Status"])
        return switchgear
```

### 2.2 边缘数据处理流程

基于IEC 61499标准的分布式功能块设计：

```
[传感器采集] → [数据预处理] → [边缘分析] → [本地决策]
                    ↓
              [云平台同步] → [历史存储] → [AI模型训练]
```

边缘侧执行的关键算法：

```python
# 设备健康指数计算（边缘侧）
def calculate_health_index(discharge, temp_rise, operations):
    """
    HI = 100 - (放电权重*放电值 + 温升权重*温升值 - 操作次数衰减)
    """
    w_discharge = 0.4  # 局放权重
    w_temp = 0.35      # 温升权重
    w_ops = 0.25       # 操作次数权重
    
    hi = 100 - (
        w_discharge * normalize(discharge, 0, 100) +
        w_temp * normalize(temp_rise, 0, 80) +
        w_ops * min(operations / 10000, 1) * 10
    )
    
    return max(0, min(100, hi))  # 限制在0-100区间
```
