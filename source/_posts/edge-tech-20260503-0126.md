## 引言：为什么IEC 61131-3仍是边缘控制编程的基石？

在工业边缘控制领域，IEC 61131-3标准自1993年发布以来，一直是PLC和边缘控制器编程的全球通用语言。尽管IT技术（如Python、C++）不断渗透到工业现场，IEC 61131-3的五种编程语言因其**确定性执行、实时性保障、硬件亲和性**，在边缘控制场景中依然不可替代。

本文将深入对比IEC 61131-3定义的五种编程语言（LD、FBD、SFC、ST、IL），结合施耐德电气Modicon M262等边缘控制器的实际工程案例，为工程师提供选型决策框架。

## IEC 61131-3五种语言快速对比

| 语言 | 全称 | 适用场景 | 学习曲线 | 执行效率 | 边缘控制适用性 |
|------|------|---------|---------|---------|--------------|
| **LD** | Ladder Diagram（梯形图） | 继电器逻辑替代、简单开关量控制 | ★☆☆☆☆ | 高 | ★★★☆☆ |
| **FBD** | Function Block Diagram（功能块图） | 过程控制、模拟量处理、复杂逻辑封装 | ★★☆☆☆ | 高 | ★★★★★ |
| **SFC** | Sequential Function Chart（顺序功能图） | 批处理、状态机、多步骤流程 | ★★★☆☆ | 中 | ★★★★☆ |
| **ST** | Structured Text（结构化文本） | 复杂算法、数据处理、数学运算 | ★★★★☆ | 中 | ★★★★★ |
| **IL** | Instruction List（指令表） | 底层优化、遗留系统维护 | ★★★☆☆ | 最高 | ★★☆☆☆ |

> **注**：IL（指令表）在IEC 61131-3:2013版中已被标记为"不推荐"，新项目建议使用ST替代。

## 一、梯形图（LD）：电气工程师的老朋友

### 核心特点
- 图形化语言，继承继电器控制电路的设计思维
- 左母线（LHS）到右母线（RHS）的"能流"逻辑
- 易于现场电工理解和维护

### 边缘控制适用性
在Modicon M262等边缘控制器中，LD适合处理**本地I/O的紧急停机逻辑**、**安全联锁**等需要快速响应的场景：

```plaintext
|--[/]----[ ]----[ ]----( )--|
|  急停   启动   复位   运行  |
|--[ ]-----------------------|
|  运行                       |
```

**优点**：直观、易调试、硬件执行效率高
**缺点**：复杂算法表达困难，代码复用性差

## 二、功能块图（FBD）：边缘控制的首选语言

### 核心特点
- 基于信号流的功能块连接
- 支持复杂数据类型的输入输出
- 天然适合封装和复用

### 工程案例：Modicon M262的EcoStruxure边缘架构

在施耐德EcoStruxure边缘控制方案中，FBD是**边缘控制器与工业网关协同**的核心编程范式：

```plaintext
┌─────────┐     ┌─────────┐     ┌─────────┐
│ 传感器  │────>│ 滤波FB  │────>│ 控制FB  │────> 执行器
└─────────┘     └─────────┘     └─────────┘
                     ↑                ↑
               边沿检测           PID算法
```

**代码示例（FBD功能块定义）**：
```structured-text
FUNCTION_BLOCK EdgeFilter
VAR_INPUT
    RawValue : REAL;    // 原始传感器值
    Threshold : REAL;   // 边沿检测阈值
END_VAR
VAR_OUTPUT
    FilteredValue : REAL;
    RisingEdge : BOOL;
END_VAR
VAR
    PrevValue : REAL;
END_VAR

// 边沿检测逻辑
IF RawValue > Threshold AND PrevValue <= Threshold THEN
    RisingEdge := TRUE;
ELSE
    RisingEdge := FALSE;
END_IF;

FilteredValue := (RawValue + PrevValue) / 2.0;  // 简单滑动平均
PrevValue := RawValue;
```

**优势**：在边缘控制器上，FBD块可直接映射到硬件加速模块，实现μs级响应。

## 三、顺序功能图（SFC）：多状态流程的天然表达

### 核心特点
- 步骤（Step）+ 转移（Transition）的图形化描述
- 支持并行分支、选择分支
- 符合IEC 60848标准（GRAFCET）

### 边缘控制场景：柔性制造单元（FMC）控制

在边缘控制器驱动的柔性制造系统中，SFC完美描述**多工位协同流程**：

```plaintext
[初始步] --TR1--> [上料] --TR2--> [加工] --TR3--> [检测] --TR4--> [下料]
                     |          |          |
                     └----TR5--┴----TR6--┘ (异常处理分支)
```

**工程价值**：边缘控制器通过SFC实现的流程控制，可在本地完成99%的逻辑判断，仅将状态数据上云，节省80%以上的通信带宽。

## 四、结构化文本（ST）：边缘控制器的"高级语言"

### 核心特点
- Pascal/ADA风格的高级文本语言
- 支持复杂数学运算、循环、条件判断
- 可调用IEC 61131-3标准库和自定义库

### 实战案例：边缘控制器的数据预处理

边缘控制器常需在本地完成数据聚合、滤波、特征提取，再上传云端。ST是实现这些算法的理想选择：

```structured-text
// 边缘控制器振动信号特征值计算
FUNCTION CalcVibrationFeatures : BOOL
VAR_INPUT
    RawData : ARRAY[1..1024] OF REAL;  // 振动原始数据
END_VAR
VAR_OUTPUT
    RMS : REAL;        // 均方根值
    Peak : REAL;       // 峰值
    CrestFactor : REAL; // 峰值因子
END_VAR
VAR
    i : INT;
    SumSq : REAL := 0.0;
END_VAR

// 计算RMS
FOR i := 1 TO 1024 DO
    SumSq := SumSq + RawData[i] * RawData[i];
END_FOR;
RMS := SQRT(SumSq / 1024.0);

// 计算峰值
Peak := 0.0;
FOR i := 1 TO 1024 DO
    IF ABS(RawData[i]) > Peak THEN
        Peak := ABS(RawData[i]);
    END_IF;
END_FOR;

// 计算峰值因子
IF RMS > 0.0 THEN
    CrestFactor := Peak / RMS;
ELSE
    CrestFactor := 0.0;
END_IF;

CalcVibrationFeatures := TRUE;
```

**边缘计算价值**：上述特征值计算在Modicon M262上仅需2ms，若上传1024点原始数据到云端，仅网络延迟就超过50ms。

## 五、选型决策框架：工程实践指南

### 场景驱动选型矩阵

| 控制需求 | 推荐语言 | 理由 |
|---------|---------|------|
| 紧急停机、安全联锁 | LD | 硬件级执行，响应最快 |
| PID调节、模拟量处理 | FBD | 图形化调参，直观高效 |
| 批次生产、多步骤流程 | SFC | 状态机天然表达 |
| 数据预处理、复杂算法 | ST | 文本语言灵活度高 |
| 遗留系统维护 | IL/ST | 依系统现状而定 |

### 混合编程：边缘控制器的黄金组合

现代边缘控制器（如Modicon M262）支持**多语言混合编程**：
- 用**LD**实现安全逻辑（符合安全规范）
- 用**FBD**实现过程控制（便于工艺人员理解）
- 用**ST**实现边缘计算算法（发挥控制器算力）
- 用**SFC**管理整体流程（清晰的状态管理）

## 总结与展望

IEC 61131-3五种语言各有千秋，**没有"最好"的语言，只有"最适合"的选择**。在边缘控制时代，工程师需要：
1. **掌握多语言混合编程**，根据场景灵活选型
2. **理解边缘-云端分工**，将实时控制留在边缘，将数据分析交给云端
3. **拥抱开放自动化**，学习IEC 61499、OPC UA等新技术与IEC 61131-3的融合
