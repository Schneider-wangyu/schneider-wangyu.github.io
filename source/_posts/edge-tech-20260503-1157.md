# 深入理解IEC 61131-3 Structured Text编程：边缘控制器的实战技巧

> 本文深入探讨IEC 61131-3标准下的Structured Text(ST)编程语言在边缘控制器中的应用，结合EcoStruxure Machine专家级编程环境，提供可落地的代码示例与实战技巧

## 引言

在工业边缘控制领域，边缘控制器（Edge Controller）作为连接现场设备与云端平台的桥梁，其编程语言的效率和可靠性至关重要。IEC 61131-3作为PLC编程的国际标准，定义了五种编程语言，其中Structured Text（结构化文本，简称ST）以其强大的数据处理能力和类似高级语言的语法特性，成为边缘控制器编程的首选语言。本文将详细讲解ST语言的核心语法，并通过实际案例展示其在边缘控制器配置与调试中的应用。

## Structured Text核心语法

### 变量声明与数据类型

ST语言采用强类型系统，支持以下核心数据类型：

| 数据类型 | 说明 | 示例 |
|---------|------|------|
| BOOL | 布尔值 | TRUE/FALSE |
| INT/DINT | 整型 | 16/32位 |
| REAL/LREAL | 浮点 | 单/双精度 |
| STRING | 字符串 | 'Hello' |
| TIME | 时间类型 | T#1s |

```st
// 边缘控制器变量声明示例
VAR
    rTempValue     : REAL;           // 温度传感器值
    iPressure     : INT;           // 压力值
    bValveState   : BOOL;           // 阀门状态
    sDeviceID     : STRING(20);     // 设备ID
    tSampleTime   : TIME;           // 采样周期
END_VAR
```

### 条件与循环结构

ST语言支持丰富的控制结构，便于实现复杂逻辑：

```st
// 条件语句示例：边缘数据预处理
IF rTempValue > 80.0 THEN
    bValveState := TRUE;
    iAlarmLevel := 2;  // 高温报警
ELSIF rTempValue > 60.0 THEN
    bValveState := FALSE;
    iAlarmLevel := 1;  // 低温预警
ELSE
    bValveState := FALSE;
    iAlarmLevel := 0;   // 正常
END_IF

// FOR循环：批量数据处理
FOR i := 0 TO 9 DO
    arrRawData[i] := arrRawData[i] * 0.1;  // 单位转换
END_FOR
```

## 边缘控制器实战：数据滤波与边缘计算

### 滑动平均滤波算法

在边缘控制器中，现场数据往往存在噪声，ST语言可以轻松实现数字滤波：

```st
// 滑动平均滤波功能块
FUNCTION_BLOCK MovingAverage
    VAR_INPUT
        rInput  : REAL;
        iWindowSize : INT := 10;
    END_VAR
    VAR_OUTPUT
        rOutput : REAL;
    END_VAR
    VAR
        arrBuffer : ARRAY[0..99] OF REAL;
        iIndex  : INT;
        rSum   : REAL;
    END_VAR

    // 更新缓冲区
    arrBuffer[iIndex] := rInput;
    iIndex := (iIndex + 1) MOD iWindowSize;
    
    // 计算平均值
    rSum := 0;
    FOR j := 0 TO iWindowSize - 1 DO
        rSum := rSum + arrBuffer[j];
    END_FOR;
    rOutput := rSum / TO_REAL(iWindowSize);
END_FUNCTION_BLOCK
```

### MQTT边缘推送配置

基于ST的边缘控制器可以直接集成MQTT协议，实现数据上云：

```st
// 边缘数据推送配置
METHOD PublishToCloud
    VAR
        stPayload : STRING(500);
    END_VAR
    
    // JSON payload构建
    stPayload := CONCAT('{"device_id":"', sDeviceID);
    stPayload := CONCAT(stPayload, '","temperature":');
    stPayload := CONCAT(stPayload, REAL_TO_STRING(rTempValue));
    stPayload := CONCAT(stPayload, ',"timestamp":');
    stPayload := CONCAT(stPayload, UDINT_TO_STRING(tCurrentTime));
    stPayload := CONCAT(stPayload, '}');
    
    // 调用MQTT发布功能块
    MQTTClient.Publish('edge/data', stPayload);
END_METHOD
```
